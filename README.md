# bajeri

Compact “arena” allocator for tackling more complex projects.  

## Prerequisites

- **For setting up the project:**
  - `Rust`
  - `just` (install by running `cargo install just`)
- **For deployment:**
  - `Git`
  - `Rust`
  - An agentic code editor (mainly for CI/CD and deployment)

## Useful Commands

```sh
# Run just to set up the project
just

# Run the project (Cargo will build it automatically if needed):
cargo run # You can also add a --release flag

# Run the test suite, including doctests:
just test

# Generate the API docs and open them in a browser:
cargo doc --open
```

## Development

For development, check out `AGENTS.md`. If there are no tests or documentation, they can be generated by entering the following commands in your agent chat window:

```sh
# For formatting and committing your code locally.
do commit

# For running 'do commit', testing, and pushing your code to a remote repository.
do push

# For running the whole CI process and publishing your work on crates.io.
do publish
```

## Example

```rust
use bajeri::Arena;

let mut arena = Arena::new();
let wolf = arena.insert("wolf");
let eagle = arena.insert("eagle");

assert_eq!(arena.get(wolf), Some(&"wolf"));
assert_eq!(arena.remove(eagle), Some("eagle"));

let bear = arena.insert("bear");
assert_eq!(bear.index(), eagle.index());
assert_eq!(arena.get(eagle), None);
assert_eq!(arena.get(bear), Some(&"bear"));
```
